## О проекте

**DraftLens** — это на 100% легальный и безопасный браузерный помощник для игроков в **Dota 2** (в духе *Albion Data Project* / *Stratz* / *Tracker.gg*). Проект полностью разработан с помощью нейросети без вмешательства в файлы клиента игры или память процесса `dota2.exe` — все расчёты выполняются исключительно через публичные Web API (**OpenDota API**, **Steam OpenID 2.0** и официальный **Valve/Steam CDN**).

### Главные возможности:
* 🔍 **Вход через Steam или мгновенный поиск:** по `Steam ID32`, `Steam ID64`, ссылке на профиль (`Steam / Dotabuff / Stratz / OpenDota`) или по никнейму.
* 🏆 **Определение твоей лучшей роли (50 / 100 / 250 / 500 / 1000 матчей):** расчёт винрейта, KDA, GPM/XPM и индекса импакта по всем 5 позициям (`Carry, Mid, Offlane, Soft Support, Hard Support`).
* 👥 **Личный пул героев:** сортировка по количеству игр (твои мейны), винрейту или KDA + сравнение с метой текущего патча в твоём ранг-брекете.
* ⚔️ **Интерактивный симулятор драфта + Анализ баланса команды:**
  * Режимы **«Пул + Мета»**, **«Личный пул»** и **«Только Мета»** (многофакторный рейтинг патча: брекет + High MMR, про-сцена, 7-дневный тренд и профильные позиции).
  * Разделение слотов **«Ты»** (по цвету слота или кнопкой `Я`), **«Союзники»** и **«Враги»**.
  * 6 индикаторов баланса союзного пика: **Контроль/Станы, Инициация, Живучесть/Танк, Урон в драке, Пуш вышек, Сейв/Хил** + предупреждения по составу.
* 🎥 **Оверлей поверх игры (Always-on-Top PiP) и Live-сканер стадии пиков:**
  * **Авто-чтение пиков с экрана Dota 2** через стандартный браузерный захват окна (`Screen Capture`) с поддержкой стандартных иконок, Аркан/Личностей и высоких уровней Dota Plus (включая 22+ ранг).
  * **Пробив противников по нику / ID за последние 20 игр** (поиск спамеров 1 героя и игроков на лузстрике).
  * **Режим «⚡ Всё на 1 экране (HUD)»** и вынос плавающего окна поверх игры без `Alt+Tab`.
* 📦 **Актуальные билды под патч:** стартовый закуп, предметы по стадиям (`Early / Mid / Late game`) со стоимостью и описанием, порядок прокачки способностей 1–18 и таланты.

## Локальный запуск для разработки

```bash
git clone https://github.com/tapan06/draftlens.git
cd draftlens
npm install
npm run dev
```

Сборка продакшен-версии:

```bash
npm run build
```
