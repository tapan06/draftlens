## О проекте

**DraftLens** — это на 100% легальный и безопасный браузерный помощник и PWA-приложение для игроков в **Dota 2** (в духе *Albion Data Project* / *Stratz* / *Tracker.gg*).  
Приложение **не вмешивается** в файлы клиента игры или память процесса `dota2.exe` — все расчёты выполняются исключительно через публичные Web API (**OpenDota API**, **Steam OpenID 2.0** и официальный **Valve/Steam CDN**).

### Главные возможности:
* 🔍 **Вход через Steam или мгновенный поиск:** по `Steam ID32`, `Steam ID64`, ссылке на профиль (`Steam / Dotabuff / Stratz / OpenDota`) или по никнейму.
* 🏆 **Определение твоей лучшей роли (50 / 100 / 250 / 500 / 1000 матчей):** расчёт винрейта, KDA, GPM/XPM и индекса импакта по всем 5 позициям (`Carry, Mid, Offlane, Soft Support, Hard Support`).
* 👥 **Личный пул героев:** сортировка по количеству игр (твои мейны), винрейту или KDA + сравнение с метой текущего патча в твоём ранг-брекете.
* ⚔️ **Интерактивный симулятор драфта + Анализ баланса команды:**
  * Режимы **«Пул + Мета»**, **«Личный пул»** и **«Только Мета»** (чистый рейтинг патча без личной статистики).
  * 6 индикаторов баланса союзного пика: **Контроль/Станы, Инициация, Живучесть/Танк, Урон в драке, Пуш вышек, Сейв/Хил** + предупреждения по составу.
* 🎥 **Оверлей поверх игры (Always-on-Top PiP) и Live-сканер стадии пиков:**
  * **Авто-чтение пиков с экрана Dota 2** через стандартный браузерный захват окна (`Screen Capture`) с авто-калибровкой по 10 слотам игроков и защитой от срабатывания в главном меню и на медалях рангов.
  * **Пробив противников по нику / ID за последние 20 игр** (поиск спамеров 1 героя и игроков на лузстрике).
  * **Режим «⚡ Всё на 1 экране (HUD)»** и вынос плавающего окна поверх игры без `Alt+Tab`.
* 📦 **Актуальные билды под патч:** стартовый закуп, предметы по стадиям (`Early / Mid / Late game`) со стоимостью и описанием, порядок прокачки способностей 1–18 и таланты.
* 📲 **Установка как приложение (PWA):** нажми кнопку **«Скачать как приложение»** в шапке сайта, чтобы установить DraftLens на Рабочий стол Windows или на смартфон как отдельную программу без адресной строки браузера.

## Как установить как приложение (по ссылке)

1. Открой **[https://draftlens-dota2-assistant.netlify.app](https://draftlens-dota2-assistant.netlify.app)** в браузере Chrome, Edge, Opera GX или на телефоне.
2. Нажми кнопку **«Скачать как приложение»** в правом верхнем углу (или значок установки приложения в адресной строке браузера).
3. Приложение появится на Рабочем столе и в меню «Пуск» как отдельная программа.

## Как выложить на свой GitHub и включить авто-обновление

В проекте уже настроен GitHub Actions workflow (`.github/workflows/deploy-pages.yml`) и конфигурация для Netlify (`netlify.toml`) и Vercel (`vercel.json`).

```bash
# 1. Инициализация и первый коммит (уже подготовлено в папке проекта)
git init
git branch -M main
git add .
git commit -m "Initial release: DraftLens by Memory Shards Studio"

# 2. Создай пустой репозиторий на https://github.com/new и привяжи его:
git remote add origin https://github.com/<твой-логин>/draftlens.git
git push -u origin main
```

После пуша на GitHub ты можешь:
* В настройках репозитория (**Settings → Pages → Build and deployment → Source: GitHub Actions**) включить бесплатный хостинг **GitHub Pages**;
* Либо привязать репозиторий к своему проекту в **Netlify** / **Vercel**, чтобы каждый `git push` автоматически обновлял сайт.
